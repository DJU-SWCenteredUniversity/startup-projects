# 창업프로젝트 결과물

[사업단 홈](https://github.com/DJU-SWCenteredUniversity) · [학생 프로젝트 공통 템플릿](https://github.com/DJU-SWCenteredUniversity/sw-project-template)

창업프로젝트의 아이디어 요약·시제품·검증·발표·공개 가능한 결과보고서를 연도별로 보관하고 연결하는 공간입니다. **현재는 목록과 작성 양식을 준비한 단계이며 실제 결과물은 등록 전입니다.**

| 메뉴 | 내용 |
|---|---|
| [2026년 프로젝트](archive/2026/README.md) | 해당 연도 프로젝트와 공개 결과물 목록 |
| [프로젝트 소개 양식](templates/project.md) | 개요·결과물·실행 방법·공개 확인 |
| [학생팀 개발 안내](DEVELOPMENT.md) | 연도별 조회·등록·검수·인계 범위 |

## 기본 구조

```text
archive/2026/README.md               연도별 목록
archive/<연도>/<프로젝트ID>/README.md   프로젝트 소개
archive/<연도>/<프로젝트ID>/reports/   공개 가능한 보고서
archive/<연도>/<프로젝트ID>/slides/    발표 자료
templates/project.md                작성 양식
DEVELOPMENT.md                      개발·인계 안내
```

코드는 각 팀의 프로젝트 저장소에 두고 이 아카이브에서 연결합니다. 공개가 확인된 보고서·발표 자료만 필요에 따라 보관하고, 큰 영상·시연 자료는 공개 가능한 원문 링크로 연결합니다. 새 연도에는 `archive/<연도>/README.md`를 추가합니다.
